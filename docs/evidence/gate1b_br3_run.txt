== Why the delete runs on its own ==
On a window far from the data (2000-01-01): DELETE alone, then a batch of 3 INSERTs: 3 rows,
and 3 again when repeated. DELETE inside the same batch as the INSERTs: 0 rows. Every
statement in a batch gets one timestamp, and at equal timestamps the delete wins.
