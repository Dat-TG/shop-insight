"""E5 - why a price filter cannot skip any silver row group, for the indexing presentation.

Question: Canva page 17 says zone maps (per-row-group min/max in the Parquet footer) only
help when close values sit in the same row group. ShopInsight's own example is the price
column: every silver row group holds both cheap and expensive items, so a filter such as
price > 1000 cannot rule out a single row group, although few rows match.

  1  footer statistics of price for every silver row group (read with DuckDB parquet_metadata)
  2  for price > v, how many row groups a reader could skip (max <= v) and how many rows match
  3  every row group, one line each

This is read from the footers only. No Spark query filtering on price was run or timed,
and no ShopInsight screen filters by price.

Run from the repo root:  .venv/bin/python presentation_price_zonemap.py > docs/evidence/presentation_price_zonemap.txt
"""

import os
import platform
import subprocess
import sys

       CAST(stats_min_value AS DOUBLE) AS price_min,
       CAST(stats_max_value AS DOUBLE) AS price_max
FROM parquet_metadata('{SILVER}')
WHERE path_in_schema = 'price'
ORDER BY file_name, row_group_id
"""

    print(f"date        {datetime.datetime.now().astimezone().isoformat(timespec='seconds')}")
