# ShopInsight — Python dependencies. Exact pins (==), never minimums.

# pyspark==4.1.3 is load-bearing. PySpark 3.5.x SEGFAULTS on Python 3.14: its
# vendored cloudpickle 2.x calls pickle._getattribute, which changed in 3.14.
# cloudpickle serialises every foreachBatch closure, so the crash would land on
# the Cassandra write path and only show up in W40. Never upgrade it on your own.
#
# py4j is pyspark's own dependency, pinned too so all four machines match.
#
# Adding a package: pin the exact version, in the same PR that first imports it.
